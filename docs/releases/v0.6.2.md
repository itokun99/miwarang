# Miwarang Senpi Delegate v0.6.2

Uses each harness's configured model and agent routing while keeping Command Code delegation available.

## Fixed

- OpenCode sessions now omit Miwarang-selected models, use the configured OpenCode default, and run through the `orchestrator` agent without querying the model catalog.
- Model candidate selection no longer filters routes by `freeOnly` or catalog cost. OpenCode routes do not inherit `defaultModels`.

## Included

- Command Code headless runs enable the `agent` and `agent_output` tools so its General agent can delegate to agents available in that harness.
- Command Code examples keep free candidates ahead of the configured low-cost candidates.
- Routing, background wait/cancel, and native-task policy are split into behavior-focused modules, with corresponding test suites split by behavior.
- README and configuration examples document the harness-owned OpenCode default and Command Code agent routing.
