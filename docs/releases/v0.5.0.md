# Miwarang Senpi Delegate v0.5.0

Backend and model selection now stays inside Miwarang instead of leaking
parent OMO model choices across harnesses.

## Fixed

- An explicit `backend` override now uses the matching configured fallback
  route and its harness-specific model list. Command Code no longer receives
  `opencode/...` model IDs from an OpenCode primary route.
- Invalid explicit model errors now tell callers to omit the override and let
  Miwarang select from the target backend's live catalogue.
- Tool guidance now treats `omo.jsonc` as intent/category input only. Agents
  are told not to copy the OMO session model or backend into
  `miwarang_delegate`.

## Included

- Regression coverage for cross-harness backend overrides and live model
  selection.
- README and `config.example.json` document the free-first, low-cost fallback
  chain and the intent-only routing rule.

## Verification

- `bun test`: 194 passing tests, 0 failures across 6 files.
- LSP diagnostics for `src/config.js` and `src/extension.js`: no errors.
- Local `category:deep-high` resolver with `backend: "commandcode"` selected
  `reflection/beam:free` without running a delegated task.
