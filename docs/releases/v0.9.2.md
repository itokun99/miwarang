# Miwarang Delegate v0.9.2

Phase 2 of the roadmap from the v0.9.1 research run: Miwarang becomes callable
from any MCP-speaking host, not only Senpi/OMO. No delegation semantics
changed; the Senpi extension keeps its exact tool surface.

## Host-neutral service (refactor)

The delegate/wait/cancel orchestration moved out of the Senpi extension into
`src/service.ts` (`createMiwarangService`). The extension now adapts that
service to Senpi tool callbacks, and background run tracking still drives the
session status line. This is the seam the MCP transport and future host
adapters consume.

## MCP stdio server

`src/mcp-server.ts` runs over stdio and exposes three tools over JSON-RPC 2.0
(MCP protocol `2024-11-05`):

- `miwarang_delegate` — prompt-driven delegation with optional `mode`,
  `backend`, and `cwd`.
- `miwarang_wait` — resolve a background run.
- `miwarang_cancel` — cancel a background run.

Every call returns the v1 result envelope as part of the tool output, so a
host can branch on terminal state without re-parsing backend-specific
payloads. Configure it in any MCP host, for example Claude Code:

```json
{ "mcpServers": { "miwarang": { "command": "bun", "args": ["/path/to/miwarang/src/mcp-server.ts"] } } }
```

## Delegation skill

`skills/miwarang/SKILL.md` (skill id `miwarang`, v1.1.0) documents when to
delegate, the tool contract, the response envelope, and per-host wiring
recipes, so a host can load the guidance alongside the MCP server.
