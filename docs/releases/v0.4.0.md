# Miwarang Senpi Delegate v0.4.0

Foreground delegations can now fail over from an exhausted OpenCode route to an explicitly configured backend such as Command Code.

## Fixed

- Free-tier exhaustion across every configured OpenCode model no longer ends a foreground delegation when the route declares a usable fallback backend.
- A route with no usable model in its live catalogue can select its next configured backend before execution.

## Included

- Route-level `fallbacks` accept an ordered list of backend/model route objects, each with its own model policy and optional agent.
- Provider failures continue through fallback backends only for foreground OpenCode runs. Explicit `model` or `backend` overrides remain single-route, and background runtime failures remain observable through `miwarang_wait`.
- `README.md` and `config.example.json` document and demonstrate a Command Code fallback.
