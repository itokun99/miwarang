# Miwarang Senpi Delegate v0.1.1

Fixes result reporting for OpenCode v2 sessions and stops masking CLI failures.

## Fixed

- `wait` and foreground delegation now return the newest assistant step that has text. The OpenCode message API returns messages newest-first, so the previous picker returned the run's opening line, or failed with "returned no assistant text", while the session held a complete report.
- A timed-out `opencode api` invocation is now reported as exit 124 with its stderr preserved, instead of exit 1 with the cause dropped.

## Included

- MIT license, contributing guide, and license metadata in `package.json`.

## Verification

- `bun test`: 29 passing tests, including regressions for descending message order, assistant steps without text, and timeout-shaped CLI failures driven through a real child process.
- Live end-to-end against local OpenCode v2 sessions: `wait` returned the full final reports (5,147 and 6,765 characters) where the previous code returned a 48-character opening line or an error.
- The new tests run against the pre-fix source: 6 failing expectations, confirming they catch the defect.
