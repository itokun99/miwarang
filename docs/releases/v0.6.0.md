# Miwarang Senpi Delegate v0.6.0

Background delegation now uses a direct `runId`/`sessionId` lifecycle without
creating child OMO or DAG watcher processes.

## Fixed

- Removed the DAG watch bridge that could orphan child OMO sessions or remain
  stuck waiting for a probe result after the delegated process ended.
- Removed `dagWatch` configuration and validation.
- Background start failures still exhaust configured model/backend fallbacks
  before returning an error.

## Included

- `miwarang_delegate(mode: "background")` returns the backend-specific run
  identifier directly.
- The main OMO agent can start multiple background delegations and call
  `miwarang_wait` or `miwarang_cancel` for each returned identifier.
- README and example configuration document direct lifecycle tracking without
  DAG children.

## Verification

- `bun test`: 179 passing tests, 0 failures across 6 files.
- Multi-background regression: five background runs completed through
  `miwarang_wait` without a DAG child.
- `git diff --check` passed and LSP diagnostics for changed source were clean.
