# Miwarang Senpi Delegate v0.7.0

The koma harness (koma.run) joins the delegation catalog as a `koma-sdk` backend
that speaks koma's public SDK protocol, so its bundled free model can serve as an
extra fallback on the Command Code lanes.

## Included

- `src/backends/koma.js`: a `koma-sdk` backend that drives `koma sdk serve` over
  its JSON Lines protocol (`create`, `submit`, `state` events, `interrupt`,
  `detach`). The adapter is spawned with an argv array and the prompt travels over
  its stdin, so nothing is interpolated into a shell. A delegation returns the
  newest non-empty assistant message, and `miwarang_cancel` interrupts the active
  turn.
- `koma-sdk` is registered in `createBackends`, and koma quota failures classify
  like other command candidates so cross-backend fallbacks continue.
- Koma has no reply-printing headless mode: `koma run --prompt … --once` prints
  only session metadata (`session_id=`, `status=idle`), which is why the backend
  targets the SDK adapter instead of the `command` backend.
- `config.example.json` adds the `koma` backend and appends it as the final
  fallback on `category:quick`, `category:writing`, and the three
  `agent:omo-native-*` routes, leaving existing primaries and ordering unchanged.
- README documents the koma backend, its free model (`koma/apple`, provider
  `koma free`), and the optional session `policy` override.

## Fixed

- `cancel()` on a koma run now settles its own completion before returning.
  The defect was caught during release verification, before this version shipped:
  without a status poll to correct it, the run record and the session tracker were
  left non-terminal (`running`) after a cancellation.

## Verification

- `bun test`: 185 passing tests, 0 failures, 350 assertions across 18 files
  (11 new koma backend tests).
- Real-surface proof: delegating through `executeDelegate` with the installed user
  config reached koma as `backendId=koma`, `model=koma/apple`, and returned
  `MIWARANG_KOMA_E2E_OK` in ~2.4 s.
- Background lifecycle against koma: `start` returned a `run_<uuid>` in state
  `running`; `wait` returned `completed` with `MIWARANG_KOMA_BG_OK`; `cancel`
  returned `cancelled` and left the run record terminal.
- Mutation check: reverting the newest-assistant extraction and removing the
  failed-turn branch each failed only its own test; the source restored
  byte-identical.
- `setupExtension` composes both the example config and the installed user config
  without error, and both pass `validateConfig`. The README configuration block
  is byte-identical to `config.example.json` (3608 bytes).
