# Miwarang Delegate v0.10.3

The Miwarang tool and its Agent Skill now have one canonical repository.

## Consolidated skill source

- Moved the complete `miwarang` skill guidance and four reference files into
  `skills/miwarang/` in this repository.
- Added `skills.sh.json` display metadata and `npm run check:skill`.
- The supported GitHub install command is:

  ```sh
  npx skills add itokun99/miwarang --skill miwarang
  ```

- `npx skills add itokun99/miwarang --list` discovers the skill directly from
  the unified repository. The skills CLI's npm dependency sync can also find
  `skills/miwarang/SKILL.md`, but that feature is experimental.
- The old `itokun99/miwarang-skill` repository is retained as a migration
  pointer. Its repository and history are not deleted or archived.

## Package readiness

- Package `miwarang` is no longer marked private and includes the installer,
  runtime, host bundles, skill, references, and skills.sh metadata.
- `npm pack --dry-run --json` lists all expected package and skill files.
- The npm registry returned 404 for `miwarang` when checked, so the name was
  available at that time. The package is prepared but was not published.
