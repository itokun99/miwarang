# Miwarang Delegate v0.9.3

Branding and documentation release. No code behavior changes.

## Renamed

- Project name: **Miwarang Senpi Delegate** → **Miwarang Delegate**
  (npm/package name `miwarang-delegate`). The tool was no longer
  Senpi-specific: the same delegation chain now runs inside Senpi/OMO as an
  extension and inside any MCP-speaking host through the stdio MCP server.

## Repository description

- GitHub repository description set to: "Unified prompt-driven delegation
  tool: hand tasks to OpenCode CLI, Command Code, Koma, or any CLI agent
  harness through a delegation chain with fallbacks, durable wait/cancel, and
  an MCP server — while every harness keeps owning its model and agent."

## Documentation

- README updated for the new name and extended with an **MCP server** section
  (stdio launch command and a Claude Code `.mcp.json` example) and a
  **Delegation skill** section pointing at `skills/miwarang/SKILL.md`.
- `CONTRIBUTING.md` and the v0.9.x release notes updated to the new name;
  historical release notes keep the name they shipped under.
