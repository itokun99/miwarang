# Miwarang Senpi Delegate v0.8.0

The whole extension is now TypeScript, delegation is backend-owned, and
background runs carry the OMO thread identity for main-orchestrator validation.

## Included

- **TypeScript migration.** All runtime modules and tests are TypeScript
  (`src/**/*.ts`, `test/**/*.ts`) checked with `tsc --noEmit` (strict on
  `src/`). Bun executes TypeScript directly, and a one-line
  `src/extension.js` shim keeps the installed OMO wrapper working unchanged.
- **Backend-owned agent dispatch.** Miwarang no longer probes backend model
  catalogs or selects a model per call. Backends are dispatched directly in
  configured order (primary + configured backend fallbacks) with task intent
  `{cwd, target, prompt}` plus explicit user `agent`/`model` overrides. Command
  backends own their model/agent through backend config
  (`model`/`agent` expand into `{{model}}`/`{{agent}}` argv placeholders).
- **Config validation follows the same boundary.** Command routes may omit
  `models`; malformed `models` values are still rejected. OpenCode keeps the
  guard rejecting explicit `model`/`agent` overrides.
- **OMO thread handoff.** Background runs record the OMO session id as
  `omoThreadId` alongside the backend `runId`/`sessionId`, and
  `miwarang_wait`/`miwarang_cancel` return both identifiers, so the main
  orchestrator can inspect a completed task without a second OMO agent turn.

## Removed

- `test/delegate-model-catalog.test.ts` asserted the removed model-candidate
  selection behavior and is gone with it.

## Verification

- `bunx tsc --noEmit`: exit 0 (strict, `src/`).
- `bun test`: 182 passing tests, 0 failures, 346 assertions across 17 files.
- Loader regression: `senpi -e ./src/extension.ts --no-extensions --list-models`
  exits 0 (Senpi 5.1.70); the `src/extension.js` shim also loads through
  `senpi -e ./src/extension.js --list-models` with exit 0.
- Real-surface routing proof: a probe config routed `category:writing` to the
  configured command backend with no Miwarang-selected model; the backend argv
  contained only its own configured `model` plus `target`/`prompt`.
- Focused tests cover backend-to-backend failover (OpenCode provider errors,
  command quota errors), OMO thread identity on background runs, and wait/cancel
  returning the stable thread and run identifiers.
