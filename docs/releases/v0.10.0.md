# Miwarang Delegate v0.10.0

Phase 3 of the roadmap: Miwarang ships as a native extension for the host
platforms the research run identified, all backed by the same host-neutral
service. No changes to delegation semantics.

## OpenCode V2 plugin (`integrations/opencode-plugin`)

A [V2 plugin](https://opencode.ai/docs/build/plugins/) that registers
`miwarang_delegate`, `miwarang_wait`, and `miwarang_cancel` as server tools.
`miwarang_delegate` and `miwarang_cancel` call
`ctx.permission.assert({ action: "miwarang_delegate" | "miwarang_cancel" })`
before running, so OpenCode's permission rules can allow, ask, or deny
delegation per agent. Copy the plugin into `.opencode/plugins/miwarang/`
(`index.js` is a self-contained bundle; only `@opencode/plugin` is imported and
the host provides it).

## Pi extension (`integrations/pi-extension`)

A single `miwarang` tool registered through `pi.registerTool()` covering
delegate, wait, and cancel (select with `action`, or implicitly: `prompt` →
delegate, `runId` → wait). Pi provides no sandbox for extensions, so the
extension is as trusted as the Pi process; see
[Pi extensions](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/extensions.md).

## OMP extension (`integrations/omp-extension`)

Same single-tool surface for Oh My Pi, plus an interactive exec-tier
confirmation before delegate/cancel through `ctx.ui.confirm` (disable with
`MIWARANG_OMP_CONFIRM=0`). OMP subagents run headless and cannot pause for
approval, so the gate lives in the interactive tool.
