# Miwarang Senpi Delegate v0.1.0

Initial release of a Senpi extension for delegating OMO work to a local OpenCode v2 service or a configured command-line agent.

## Included

- Senpi tools for foreground delegation, background start, wait, and cancellation.
- OpenCode v2 integration through the authenticated `opencode api` CLI.
- Live OpenCode model discovery and free-only route validation.
- Default OMO routes for `quick`, `unspecified-low`, `deep-low`, `explore`, and `librarian`.
- A generic executable-plus-argv backend with stdin or argument prompt delivery and no shell interpolation.
- Configurable model and OpenCode agent overrides.
- Background OpenCode session-ID tracking and local command-run metadata.

## Verification

- `bun test`: 23 passing tests.
- OpenCode v2.0.26 catalog: 74 models; configured free routes resolve to available zero-cost models.
- Live foreground, background/wait, cancellation, and OMO `category:quick` delegation were exercised with OpenCode free-tier models.
- Pi, Claude Code, and Codex CLI implementations were not individually installed or tested; use the generic command backend with each CLI's supported flags.
