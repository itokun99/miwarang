# Miwarang Delegate v0.10.1

One-command installation for every supported host, from a single npm package.

## Installer (`npx miwarang init`)

The package now ships a `bin` (`src/installer.ts`) with an interactive
target picker and non-interactive flags:

- **OMO / Senpi** → copies the extension into
  `~/.omo/agent/extensions/miwarang/` (all backend/service modules plus the
  `extension.js` shim), and seeds
  `~/.config/miwarang/config.json` from `config.example.json` when no config
  exists yet.
- **Pi** → copies the bundled extension to
  `~/.pi/agent/extensions/miwarang.js`.
- **OpenCode** → copies the bundled V2 plugin into
  `.opencode/plugins/miwarang/index.js`, or
  `~/.config/opencode/plugins/miwarang/` with `--global`.
- **Claude Code** → registers the MCP server in the project `.mcp.json` and
  `~/.claude/claude.json` (`mcpServers.miwarang`).
- **Other MCP host** → prints a ready-to-paste `mcpServers` snippet.

`miwarang uninstall --target <same>` removes the same artifacts. Home
directories are overridable with `MIWARANG_HOME` for testing. The package
name is now `miwarang` with `bin.miwarang` pointing at the installer.
