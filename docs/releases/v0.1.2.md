# Miwarang Senpi Delegate v0.1.2

Extends delegation to every OMO category with multi-harness routing and fixes wait/cancel routing for command-backed runs.

## Fixed

- F-1: `wait` and `cancel` no longer mis-route `run_<uuid>` ids to the first command backend. `backendForRun` now resolves the backend via the RunStore record (explicit parameter → run record → legacy prefix heuristic), so wait/cancel work without a manual `backend` parameter.

## Included

- Multi-harness routing: 10 categories plus 7 curated agents with per-category backend selection across `opencode` (free-tier models) and `commandcode`.
- Wildcard `category:*` / `agent:*` resolution plus `defaultRoute` fallback; resolution order is exact key → wildcard → default.
- Explicit `blockNativeTask` block policy: per-route flag overrides the top-level policy, so deep routes can keep native task while everything else is blocked and nudged.
- `pricePolicy` so `freeOnly` routes can target command backends (command backends drop the free-only constraint when the effective policy is `any`).
- New `commandcode` backend in `config.example.json` (`command` type, argument prompt input).
- Retry-once on an empty OpenCode model catalog (F-6), covering catalog-fetch races during delegation.
- Legacy v0.1.1 fixture compatibility kept: existing configs and run records load unchanged.

## Verification

- `bun test`: 126 → 135 passing tests, 0 failures across 5 files.
- Live e2e parallel delegation with `commandcode` + `opencode` overlap: both runs completed in 8,750 ms wall-clock, under 1.8× the longest single run (12,348 ms).
- `wait`/`cancel` without a `backend` parameter reach the correct `commandcode` run (F-1 fixed).
- `freeOnly` → command routing returns non-empty output (`"pong"`) instead of failing the free-model gate.
- Native-task hook blocks `writing` and `agent:explore` (returns the nudge object) and passes through `ultrabrain` and `deep-high` (returns `undefined`).
- 12 live routes verified against the local OpenCode v2 catalog.
- `config.example.json` covers all categories with the wildcard and `commandcode` routes; the README config block is byte-identical to `config.example.json`.
